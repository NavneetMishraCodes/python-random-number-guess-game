## 🎯 Random Number Guess Game

A fun Python command-line game where the computer generates a random number and you try to guess it.  
Your score (attempts taken) is saved for future reference.

---

### 🎮 Features
- Random number generated between 1–100
- Unlimited guessing attempts
- Hints after every guess (Too High / Too Low)
- Tracks number of attempts
- Saves player history to a file
- Simple and fun CLI gameplay

---

### 🧠 Concepts Used
This project helps beginners practice:
- Random module
- While loops
- Conditional statements
- User input handling
- File handling (append mode)
- Basic game logic design

---

### 📁 Project Structure
random-number-guess/
- main_file.py     # Main game file  
- history.txt      # Stores player history  

---

### ▶️ How to Run

1. Clone the repository
git clone https://github.com/your-username/python-mini-projects.git

2. Open the folder
cd python-mini-projects

3. Run the game
python main_file.py

---

### 🕹️ How to Play
- The computer chooses a number between **1 and 100**
- Keep guessing until you get it right
- After winning, enter your name
- Your score gets saved in **history.txt**

---

### 🎯 Learning Outcome
This project introduces beginners to **loops, game logic, and file-based score tracking**, making it a great step toward building real applications.
